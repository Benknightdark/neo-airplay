# 統一 Node.js 24 與 CI 工具路徑

## 目的與背景

驗證腳本與 Tauri runner 先前會重排 `PATH` 覆蓋 CI 選定的 Node.js，且版本檢查硬編碼為 Node.js 22。本計畫將專案統一升級至 Node.js `24.22.2`，並在略過環境準備時保留呼叫端 `PATH`。

## 目前與預期行為

- **修改前**：固定 `22.23.3`，要求 `22.x`；`NEO_AIRPLAY_SKIP_SETUP=1` 時仍重排 `PATH`。
- **修改後**：固定 `24.22.2`（接受 `>=24.22.2 <25.0.0`），由 `desktop/.node-version` 統一解析；`NEO_AIRPLAY_SKIP_SETUP=1` 時 `verify.sh`、`verify.ps1` 與 `run-tauri.mjs` 皆保留呼叫端 `PATH`。

## 限制與決策

- 維持 Bun 與 Rust 版本不變；六平台 Node.js `24.22.2` 安裝包依官方 SHA-256 清單驗證。
- 更新 `desktop-test` 的 `@types/node` 至 `^24.0.0`，並於 `desktop/package.json` 補齊 `@wdio/tauri-plugin` 開發依賴以支援全新 CI checkout 的 `vue-tsc --noEmit`。

## 工作步驟與進度

1. 更新 `desktop/.node-version`、`package.json`、驗證／啟動腳本與六平台 SHA-256。
2. 更新 `test-setup.mjs` 隔離測試，涵蓋版本邊界（`24.22.1` 拒絕、`24.22.2` 通過、22/26 拒絕）與 `NEO_AIRPLAY_SKIP_SETUP=1` 路徑保留。
3. 修正非 Windows 主機 `pwsh` 下 `PATH`/`Path` 大小寫與 `$PSHome` 前綴處理，以及 CI/CD 輔助 jobs 的 `actions/setup-node` 設定。
4. 更新本機 `~/.local/lib/neo-airplay/node-v24.22.2` 與 `~/.local/bin` 符號連結，完成全套驗證並歸檔。

## 驗證

- `bash desktop/scripts/verify.sh`：通過（型別檢查、28 項前端測試、44 項安裝與路徑測試、6 項版本測試、`cargo fmt`、33 項後端測試、Clippy、Vite 建置）。
- `pwsh desktop/scripts/verify.ps1`：通過。
- `cd desktop-test && bun run --silent test:e2e:ci`：通過（5/5 WebdriverIO 桌面 E2E）。
- 原生 Windows 與 Linux 打包由 GitHub Actions CI runner 驗證。

## 復原方式

還原本次 commit 的版本檔、鎖檔、腳本與工作流程變更；本機 `~/.local/bin/{node,npm,npx}` 可切回 `node-v22.23.3`。

已完成並通過驗證。
