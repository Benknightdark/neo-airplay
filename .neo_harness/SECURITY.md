# 安全與信任邊界

本文件依目前程式碼與 [README.md](../README.md) 記錄安全控制、信任邊界與發佈限制（近期強化紀錄見 [20261127112700_comprehensive-security-hardening.md](docs/exec-plans/completed/20261127112700_comprehensive-security-hardening.md)）。

## 應用程式與 IPC 權限

- **最小 IPC 與 CSP**：正式 capability（[default.json](../desktop/src-tauri/capabilities/default.json)）不額外授予 `core:default` 外掛權限，僅開放應用程式自訂 Tauri 指令；[tauri.conf.json](../desktop/src-tauri/tauri.conf.json) 啟用 `freezePrototype: true` 與嚴格 `csp`（移除 `'unsafe-inline'`、`asset:` 與 `data:`，限定 `base-uri 'self'`、`object-src 'none'`、`frame-ancestors 'none'`、`form-action 'self'`、`script-src 'self'`、`style-src 'self'`、`img-src 'self'` 與 `connect-src ipc: http://ipc.localhost`），開發環境規則另置於 `devCsp`。WDIO capability 與 `--e2e-profile` 暫存目錄隔離僅在 Rust `wdio` feature 與 [tauri.e2e.conf.json](../desktop-test/e2e/tauri.e2e.conf.json) 啟用。
- **執行身分與最小提權**：App 以一般使用者權限執行，不自動建立防火牆規則；僅在安裝系統套件時透過絕對系統路徑 `/usr/bin/pkexec`／`/usr/bin/sudo` 或 Windows UAC 要求授權（安裝腳本拒絕 `$HOME`、專案 `engine/` 及全域可寫目錄中的提權工具）。Windows UAC 僅以 `-ElevatedPrerequisitesOnly` 安裝系統層級前置項目（補裝 `AllUsers` 範圍 WinGet 與 `-Development` 的機器層級套件），不以系統管理員身分處理 `engine/`、MSYS2、UxPlay 或執行期檢查，並驗證 `OriginalUserSid` 格式。登入啟動僅透過 Tauri `autostart` 插件註冊或移除。

## 外部程序與本機信任邊界

- **環境淨化、無 Shell 執行與絕對系統路徑**：Rust 啟動任何外部子程序（含引擎執行、版本探測與 `/usr/bin/dns-sd`）前統一呼叫 `sanitize_child_environment` 移除 `LD_PRELOAD`、`LD_LIBRARY_PATH`、`DYLD_INSERT_LIBRARIES`、`DYLD_FRAMEWORK_PATH`、`OPENSSL_CONF`、`GCONV_PATH`、`GIO_EXTRA_MODULES`、`GST_*`、`ADB*`、`SCRCPY_*` 與 `UXPLAYRC`。`uxplay`、`adb`、`scrcpy` 與 `/usr/bin/dns-sd` 皆以 `std::process::Command` 引數陣列執行，Windows 工具與 `smoke-bundle.mjs` 以 `%SystemRoot%\System32` 絕對路徑啟動 `powershell.exe`、`tasklist.exe` 與 `taskkill.exe`（且不將 `engine/` 注入安裝或探測程序 `PATH`）。macOS `DYLD_LIBRARY_PATH` 過濾相對路徑、`..` 與符號連結；Android 引擎啟動鎖定受控 `ADB`、`SCRCPY_SERVER_PATH` 並驗證 `scrcpy-server` 為非空實體檔案。不接受前端傳入自訂安裝命令或下載 URL；macOS Terminal 安裝驗證路徑不含控制字元，並產出 `umask 077`、`0o700`、以 `exec /usr/bin/env -i` 清空環境並對所有路徑執行 `-L` 檢查的包裝腳本，配合 `osascript` `on run argv` 傳遞命令列，避免 AppleScript 與 Bash 3.2 字串／未設變數展開風險。
- **執行路徑與本機檔案安全原語**：引擎只從 Debug 的 `desktop/engine/` 或 Release 使用者資料目錄（`0o700` 建立）的 `engine/` 載入，不回退系統 `PATH`、MSYS2 或 WinGet；`find_executable` 與 `is_executable_file` 逐層檢查 `symlink_metadata` 拒絕符號連結。設定目錄與日誌目錄以 `ensure_safe_directory(..., true)` 建立並強制 Unix `0o700`；`settings.json` 與日誌 `.jsonl` 透過 `open_regular_file_secure`／`open_append_regular_file_secure`（在 Unix 上搭配 `O_NOFOLLOW` 與 `(st_dev, st_ino)` 二次驗證防 TOCTOU）與 `write_file_atomic_secure`（Unix `0o600`）存取，且分別設有 64 KiB 設定檔上限與 2 MiB／10 MiB 單日日誌讀取／尾端 1 MiB 輪替上限。子程序 stdout/stderr 使用 `read_bounded_lines` 限制單行 8 KiB，防止無換行輸出造成 OOM。
- **區網 AirPlay 驗證、Android 投影控制與輸入正規化**：使用者可選擇 AirPlay `none`（預設向下相容）、`randomPin` 或 `fixedPin`；`uxplay` 強制隔離 `UXPLAYRC` 至 `config_dir/uxplay.rc`（`0o600`）與 `uxplay.register`（`0o600`），避免讀取外部 `~/.uxplayrc` 亦不在命令列或一般日誌暴露固定 PIN。Android `scrcpy` 預設啟用 `--no-clipboard-autosync`（`androidNoClipboardSync: true`）並支援 `--no-control` 唯讀模式（`androidReadOnly`）；ADB 序號經 `is_valid_android_serial` 嚴格白名單驗證並以 `--serial=<serial>` 傳遞；`ReceiverName` 與 `AppLogEntry` 移除控制與 Unicode Bidi 字元並限制 63 UTF-8 位元組（廣播名稱）／4 KiB（單筆日誌）。
- **目錄刷新互斥與清除防護**：`DependencyManager` 強制線上工具目錄刷新與依賴維護序列化互斥，防止並發複寫 `tool-versions.json`。`clear_*` 操作預先拒絕符號連結（含懸空符號連結），且僅以受控非符號連結 `adb` 執行受環境淨化與逾時保護的 `kill-server`。
- **診斷記錄隱私**：每日 JSONL 診斷記錄包含外部程序輸出（固定 AirPlay PIN 已遮罩，其餘執行細節與 Android 裝置型號／序號仍會記錄），對外提供記錄前應先檢視內容。

## 第三方供應鏈與發佈控制

- **固定來源、傳輸強化、歸檔檢核與 TOFU 鎖定**：預設套件不含第三方投影二進位檔（`desktop/engine/` 除 `.GITKEEP` 外皆由 Git 忽略）。安裝腳本統一強制 HTTPS TLS 1.2+、禁止 URL 使用者認證資訊與非標準埠、限制最多 5 次且終點主機仍在官方白名單內（`github.com`、`codeload.github.com`、`objects.githubusercontent.com`、`release-assets.githubusercontent.com`、`raw.githubusercontent.com`、`static.rust-lang.org`、`nodejs.org`）並設 256 MiB（一般下載）／1 MiB（`SHA256SUMS.txt`）大小上限。`install.sh` 預檢 Tar/Zip Slip、`^[a-zA-Z]:` 磁碟機路徑、硬連結與非授權符號連結（`--no-same-owner --no-same-permissions`），且以 `cmake --install --prefix "$work_dir/staged"` 僅原子部署 `uxplay` 單一執行檔、macOS 排除 `python*`/`pkgconfig`/`girepository-1.0`；`install.ps1` 執行 Zip Slip／磁碟機前綴檢查、MSYS2 Tar 預檢、全域 `WinGet` `%ProgramFiles%` 路徑與 Microsoft Authenticode 驗證，並保留還原 MSYS2 `SigLevel = Required DatabaseOptional`（含縮排與 `TrustAll` 模式）。自訂 `UxPlay` 於首次 UI 確認 HTTPS 下載安裝成功後，透過 `install-result.json` 回傳 `resolvedSha256` 自動將雜湊寫入 `tool-versions.json` 並清除 `allowUnverified`（TOFU）；無雜湊且未顯式 Opt-in 的自訂偏好於載入時自動失效。
- **Linux GStreamer 版本查詢**：Debian／Ubuntu、Fedora 與 Arch 只讀取各發行版官方 HTTPS 套件頁；RHEL 使用固定 `/usr/bin/dnf`（淨化環境）執行 15 秒逾時的唯讀 `repoquery` 查詢，不執行安裝或升級。Linux 發行版由 `/etc/os-release` 的 `ID` 欄位精確判斷。
- **依賴弱點掃描與上游受阻評估**：[ci.yml](../.github/workflows/ci.yml) 對正式前端 `desktop/` 執行 `bun audit`（目前 0 已知弱點），並於 Linux job 以固定版本 `cargo-audit 0.23.0` 直接執行 `cargo audit`，並套用 [audit.toml](../desktop/src-tauri/.cargo/audit.toml) 的忽略清單進行自動化 Rust 依賴弱點掃描；下列僅餘無法非破壞升級之上游 GTK3／未編譯／測試專用項目且於 `audit.toml` 明確記錄理由：
  - Linux 限定之 `glib@0.18.5`（`RUSTSEC-2024-0429`）與 `proc-macro-error@1.0.4`（`RUSTSEC-2024-0370`），受限於 `tauri@2.x` Linux `gtk@^0.18`／`webkit2gtk@^2`。
  - Linux 限定之 `zvariant@5.15.0`、`zvariant_derive@5.15.0` 與 `zbus_names@4.3.4`（`RUSTSEC-2026-0370`／`0371`／`0372`），受限於 `tauri-plugin-single-instance@2.x` 之 `zbus@^5.9`。
  - `chrono@0.4.45`（`RUSTSEC-2026-0543`）僅作為 `tauri-utils` → `serde_with` 未啟用可選功能之鎖定項存在於 `desktop/src-tauri/Cargo.lock`，不會編譯進正式二進位檔。
  - 僅存於 `desktop-test/` 測試依賴的 `extract-zip@2.0.1`（`GHSA-jmr9-qjv8-65gv`、`GHSA-7pqw-9j4j-h8q3`）；因 [wdio.conf.ts](../desktop-test/e2e/wdio.conf.ts#L49) 採用 `driverProvider: "embedded"`，且 `desktop-test/` 不進入正式發佈檔。
- **CI/CD 最小權限、鎖定建置與發佈驗證**：CI 與 CD 的全部 `actions/checkout` 皆設定 `persist-credentials: false`（需推播版本 PR 之工作明確於步驟內以 `GH_TOKEN` 執行 `gh auth setup-git`）；[build-app.ts](../desktop/scripts/build-app.ts) 強制 `-- --locked`；[cd.yml](../.github/workflows/cd.yml) `publish-release` 產出 `SHA256SUMS.txt` 並以 `actions/attest`（`id-token: write`、`attestations: write`）為所有發佈安裝檔附加 SLSA Build Provenance Attestation。
- **尚未啟用的發佈控制**：Windows 程式碼簽章憑證與執行檔簽章尚未配置；macOS 亦僅使用 ad-hoc 簽章且未執行 Apple Developer ID Notarization。
